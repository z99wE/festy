# Security Policy

Festiya takes the security and privacy of event data and personal workspace assets seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Festiya:

1. **Do not disclose publicly**: Please avoid opening public issues for sensitive vulnerabilities.
2. **Contact maintainers**: Email security reports to `security@festiya.app` with details, reproduction steps, and impact assessment.
3. **Response timeline**: You will receive an initial response within 24 hours acknowledging your submission and outlining remediation steps.
