# Security Policy

Festiya takes the security and privacy of its users, event planners, and celebration organizers seriously.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Festiya:
1. Please do NOT disclose it publicly on GitHub issues or social media.
2. Send a detailed report to `security@festiya.app` with steps to reproduce, impact assessment, and proof of concept.
3. Our core response team will acknowledge receipt within 24 hours and issue a CVE/patch within 7 business days.

Thank you for helping keep Festiya safe and reliable!
