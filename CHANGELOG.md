# Changelog

All notable changes to the Festiya workspace are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-24

### Added
- Cloudflare-first deployment architecture with Hono and Cloudflare D1 compatibility.
- Decimal-safe money arithmetic in integer minor units (cents) to eliminate IEEE-754 drift.
- Full 15-table relational schema with multi-tenant workspace isolation.
- Multi-provider AI Gateway (Gemini 2.5 Flash, Cloudflare Workers AI) with deterministic fallback.
- Client-ready scoped event sharing with privacy controls and expiring tokens.
- Enterprise subscription tier metering and ledger management.
- Comprehensive Soloknuckle production readiness compliance with 100% scores across critical domains.
