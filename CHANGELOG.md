# Changelog

All notable changes to the Festiya celebration intelligence platform are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-28

### Added
- Interactive 3D Celebration Globe with real-time geospatial coordinate mapping.
- Event Economics Abacus with live currency conversion and category budget allocators.
- Autonomous Festi AI Copilot for day-of runs, vendor negotiation scripts, and custom prompt workflows.
- Accessible celebration category showcases for Weddings, Birthdays, Cultural Festivals, and Product Launches.
- Comprehensive end-to-end and node-based test suite for celebration core algorithms.
- Full health probe endpoints (`/healthz`) and exponential retry resilience policies.

### Changed
- Re-architected color palette to soft pastel bubblegum hues and joyful warm orange tones.
- Streamlined hero copy to focus on operational calm and festive elegance.
- Enhanced WCAG 2.1 AA keyboard accessibility and screen-reader compatibility across all interactive components.
