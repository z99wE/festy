# Contributing to Festiya

Thank you for your interest in contributing to Festiya! We are building the next generation of celebration and festival planning tools.

## Development Workflow

1. Fork or branch from `main` using descriptive conventional branch names (e.g., `feat/my-feature` or `fix/issue-description`).
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development environment:
   ```bash
   npm run dev
   ```
4. Verify tests and linting before submitting your Pull Request:
   ```bash
   npm test
   npm run lint
   npm run build
   ```

## Commit Standards

Festiya strictly follows Conventional Commits format:
- `feat: add new feature`
- `fix: resolve bug or regression`
- `docs: update documentation or guides`
- `test: add or modify test suites`
- `chore: update dependencies or build tools`

## Code of Conduct

Be kind, inclusive, and respectful in all community and code interactions. Every celebration matters!
